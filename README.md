The internet in one word. The entry is a single word written to `/output/entry.txt`:

**Doomscroll** — the endless, compulsive scroll through feed after feed, long past the point of enjoyment.

Ten letters, one word, no explanation, no second draft. It is funny because it is true, it fits the internet as a whole (the feed is where everyone lives now), and it is surprising — a modern habit turned into a single coined word, exactly what the judge rewards.

## Run it

```sh
python3 main.py
```

This writes `Doomscroll` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), mode 0644, and prints the same word to stdout.
